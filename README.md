# Supreme Scholar

A local browser app. One file. No account, no database, no install.

**Levels:** Foundation → Mortal → Scholar → Adept → Master → Transcendent → Supreme

## Use it

1. Download this repo, or open the raw `index.html`.
2. Open `index.html` in any browser.
3. Write your name. The box starts empty.
4. Add a mission, exam, step, or deadline. Mark it done.

Rank and cards stay in that browser. Clearing site data deletes them.

## Backup

- **Export JSON** saves one file of your name and cards.
- **Import JSON** reads that file back.

## Rules

XP is added only when a card is marked done.

- Easy 25
- Medium 60
- Hard 120
- Boss 250

Undo removes that XP again.
